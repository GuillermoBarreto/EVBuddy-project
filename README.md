# EVBuddy

Android app for browsing EV drivers, built with Kotlin and Jetpack Compose. Internship project.

## Features

- Driver list screen with an empty-state message when no drivers are available
- Accessible driver cards with content descriptions for screen readers
- Simple navigation between home and driver list

## Tech stack

- Kotlin
- Jetpack Compose (Material 3)
- Android Gradle with Kotlin DSL

## How to run

1. Open the project in Android Studio
2. Let Gradle sync
3. Run on an emulator or device (API 24+)

## Status

In development — the home screen is a placeholder while the driver flow is built out.
